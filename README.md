# 数字社会学（Digital Sociology）

一套面向研究与写作的数字社会学知识库与工作流，供 AI 助手在以下场景中调用：

- 数字社会学知识科普与概念解释
- 用数字社会学视角解读社会现象
- 解答数字社会学专业问题（概念、设计、判断）
- 系统学习数字社会学知识点（四周速成 / 十二周系统）
- 探讨与评估研究选题
- 撰写中英文论文（引言、理论框架、方法、讨论）
- 评审论文质量（百分制、分路线加权）
- 精读导读与学科定位

## 四条路线

| 路线 | 关心什么 | 一句话判据 |
|---|---|---|
| 平台的政治经济学 | 平台的钱从哪来、凭什么持续拿到 | 能不能指出一条可追踪的钱流 |
| 算法权力与批判 | 谁被判定、凭什么、能否申诉 | 能不能指出一个决策点与一种失效的问责手段 |
| 不平等与生活世界 | 谁得到什么、东西怎样被安放 | 能不能指出两类人做同一件事而结果不同 |
| 数字方法 | 用什么证据说话、能说到多硬 | 能不能说出数据原本为谁、为何目的生成 |

外加两层横切模块：**技术—社会理论桥**（物质性、能动性、可供性）与**学科地图**（边界、时代诊断、学习路径），以及**劳动与世代**专题补编与**中国语境**前提核对表。

## 安装

把整个 `digital-sociology` 目录放进助手的技能目录（例如 `~/.workbuddy/skills/`），或解压发行包到该目录即可。

## 使用

技能会自动在相关请求上触发。若需显式调用，直接说「用数字社会学的方法分析……」或「按数字社会学的框架帮我看看这篇稿子」。

## 说明

- 本技能面向**方法与判断**，不含书目与文献目录；所有内部引证使用 S01–S28 匿名编号，仅用于追溯与核对。
- 依据强度（材料总量、逐源精读比例、已核实的勘误、仍未核实的清单）见 `references/audit.md`。**凡引用本技能的结论，建议先读那一页。**
- 中国经验部分多为可检验命题，不是已有发现；各文件 §9 已标明前提。
