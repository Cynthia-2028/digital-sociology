# 依据强度与核对说明

> 这一页回答一个问题：**这份 skill 的每一句判断，是从哪里、以多大强度读出来的。**
> 凡要引用本 skill 的结论，先看这一页。凡本页标「未核实」的，转述时必须保留标记。

---

## 1. 源编号与匿名化约定

本 skill 的所有引证只用 **S01–S28** 这组编号，配合 PDF 物理页，例如 `（S13 p.84）`。

- 编号对应的书目信息（书名、作者、出版年、出版社）**不在本 skill 内保存**，这是刻意的：本 skill 面向方法与判断，不承担文献目录功能。
- 需要把某个编号还原成具体文献时，查工作区的抽取索引（`_ext8/_index.json` 与各抽取文本的文件名），那里保留原始文件名与页数。
- 编号一旦建立就不再变动；新增材料续编 S29 起。

## 3. 精读强度（诚实口径）

**全书按页加权精读 38.4%（2,540 页 / 6,620 页）；按字符加权 37.5%（约 543 万字符）。**

这不是「读完了」，是「按需读透了承担概念的章节」。三句话说明口径：

1. **计入精读的是逐段读过、并在笔记里留下页码的页**。目录页、索引页、纯参考文献页不计入。
2. **未计入的部分包括**：长篇案例叙事、统计附录、参考文献表、以及与本 skill 四条路线无关的章节（例如技术细节章、区域案例章）。
3. **加权方式**：单源字符量 × 该源精读页占比，求和后除以总字符量。所以长书读得少、短论文读得全，不会被平均掉。

## 4. 已核实并纠正的说法（勘误表）

以下几处是本批材料实测后与流行说法不一致的地方。**转述时以本表为准**；若本 skill 其他文件与本节冲突，以本节为准。

| 流行说法 | 实测结果 | 依据 |
|---|---|---|
| 技术驯化是「六阶段」模型 | 原始版本只有**四项**，且原文自称「four non-discrete elements or phases」；六项版本（加入商品化、想象的用户）出自后续合作者，不在原始框架内 | S21 p.31 |
| 驯化四阶段是先后相继的流程 | **不是序列**。原文前置「non-discrete」，四项在同一时期互相构成；其结构是「内／外 × 空间／时间」四格（客体化＝空间，整合＝时间） | S21 p.31、p.35 |
| 「道德经济—公共意义—家庭仪式」是三支柱 | **这三项不是原文的并列维度**。原文是道德经济、双重联结（double articulation）、以及「特定的宇宙论与仪式」；「家庭仪式」只是道德经济的一种表达形态 | S21 p.26、p.29、p.38 |
| 驯化＝抵抗或收编 | 都不是。阿米什案例的关键是「电话可以用，但不能装在家里、不能私人拥有」，属**迁移式接受** | S21 p.185、p.190 |
| 「数字护栏」是一个有定义的技术装置 | 该词在可查文本中只作为泛称出现一次、**无定义**；同功能且有定义的概念是「环境包裹」（enveloping，改造环境以适配机器的有限能力），方向与监管相反 | S24 p.54、p.172 |
| AI 伦理有一个通行的「principlism 批评」原产地 | 可查文本中**未出现**该词，也未承接生命伦理学的四原则批评；承担同一功能的是三处具体论述（原则市场、合规必要不充分、七因素不是清单） | S24 p.87、p.110、p.177 |
| 算法批判可以直接给出「算法加剧了多少不平等」 | 这条路线是**诊断学**，不是因果学：它能证明「某种不透明与某种伤害的组合已发生且手段错配」，不能给总量效应 | S12 p.7；S14 p.12 |
| 数字不平等是「接入问题」，普及后自然消解 | 接入饱和之后结果层仍有组间差；「结果层」必须用与接入无关的指标测量，否则循环论证 | S16 p.71、p.79、p.109 |
| 大数据研究的关键优势是「全样本」 | 关键优势是**成本结构与可得性**的变化；量只降随机误差，不降覆盖、构念、算法混淆三类系统误差 | S22 p.17、p.40–44 |
| 「世代差异」可以由横断调查的年龄差异直接读出 | 不能。年龄、时期、队列三者混淆；横断差异不足以识别世代效应 | S28（相应章）；`labor-and-generation.md` §3 |
| 「平台资本主义」与「技术封建主义」是同一命题的两种叫法 | 不是。前者讲平台作为资本组织形式的收益来源，后者讲占有超过剥削、需要「租金占比」的经验证据；提出者自己把门槛留作经验问题，未给阈值 | S08 p.34；S09 p.9 |
| 中国语境可直接套用「数据产权」框架 | 个人数据不可交易，平台核心资产是**接口位置**而非产权；套用会问出制度上无对应物的问题 | `political-economy-route.md` §9.1（推论，已标明） |

## 5. 仍标「未核实」的清单（引用前必须回查）

1. **驯化框架六项版本的确切出处**——本批材料只有四项；六项的归属靠记忆，未见原文，标「未核实」。
2. **「平台化」四阶段（S11 所给）的原文编号与页码**——笔记只保留了阶段名，编号未逐条核对。
3. **技术封建主义的「租金占比」阈值**——提出者明确说这是经验问题，全书未给数；不得代拟数字。
4. **算法备案条文的具体要求**——`critical-algorithmic-route.md` §9.2 只给判据，条文本身未逐条核验，写作前须查现行规定原文。
5. **中国平台用工的社保成本差**——S08 给的是「约三成」的估算（p.48），针对的是承包商身份；中国情形被参保基数改写，具体幅度本批材料无数据。
6. **S28 的 APC 处理细节**——精读 20%，只读到作者对世代效应的主张与部分辩护，未读到其统计附录；引用其方法时必须回查。
7. **S19 的人机关系研究对「机器人伴侣」的样本代表性**——案例集中在中产家庭与特定机构，样本框未核。
8. **S04 文集内 24 篇未读文章的任何具体主张**——一律不代述。
9. **S23 对「社会机器」的可验证预测**——书中多为设计愿景，已被证实/证伪的比例本批材料无法给出，标「未核实」。
10. **中文语境的「算法黑箱」政策用语与学术用语的对应关系**——S15 只指出歧义，未做系统对照。

## 6. 使用限制（五条）

1. **不要把本 skill 当原文数据库**。页码是 PDF 物理页，用于定位，不替代原文核对；正式写作引用时须回原文确认版本与页码。
2. **不要把「加权精读 37.5%」读成「可以随便断言」**。凡标「判断」「推论」「未核实」的地方，转述时必须保留标记。
3. **不要在写作中把编号写出来**。S01–S28 是内部核对工具，不是引注格式。要给读者出处，回原文取完整信息。
4. **本 skill 不含书目信息是刻意的**。若需要文献目录，另行维护，不要反向从本 skill 的编号猜书名——那会产出错误引注。
5. **中国经验部分多数是可检验命题，不是已有发现**。本批材料里真正做中国经验研究的只有 S15、S26 两份；其余「中国接口」都是基于理论的推论，已在各文件 §9 标明前提。

## 7. 如何更新

- 新增材料：放入源目录 → 跑 `_build/extract_ds.py` 一类的抽取脚本 → 精读笔记（九项结构见 `_notes8/_SPEC.md`）→ 把新编号补进 §3.1 与本文件第 1 节。
- 修正错误：先改对应路线文件被引的段落，再改本文件 §4 勘误表。**勘误表只增不删**，已修正的条目保留原文并标「已修正」，便于追溯。
- 每次更新都要重算 §3 的两个加权比例。不要沿用旧数。
