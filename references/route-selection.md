# 路线选择：四条路线怎么分、怎么问、怎么混

> 这份文件只在三种场合读：① 要向用户解释四条路线的差异；② 要开口问「你想走哪条」；③ 用户选了路线但材料与路线对不上。
> 其他时候不要读它——它会让回答变成教科书。

---

## 1. 四条路线的一句话判据

四条路线不是四个题目领域，而是四种**不同的因果箭头**。记住箭头，比记住概念表有用。

| 路线 | 因果箭头 | 一句话判据 | 它最怕的问题 |
|---|---|---|---|
| 平台政治经济学 | 所有权与接口位置 → 计价能力 → 收益分配 → 参与者选择集 | 能不能指出「钱从哪条流进来、被谁截住」 | 「平台内部的人怎么想、怎么抵抗」 |
| 算法权力与批判 | 目标函数与部署制度 → 判定 → 当事人可申诉性 | 能不能指出「哪个决策点、哪种不透明、哪种手段对它无效」 | 「到底有多少人被影响」 |
| 不平等与生活世界 | 既有资源与意义秩序 → 使用概率与安置方式 → 结果差异 | 能不能指出「同样做一件事，为什么两类人结果不同」 | 「总量上贡献了几个百分点」 |
| 数字方法 | 数据生成机制 → 可观测指标 → 分布与效应 | 能不能说出「这份数据原本为谁、为什么目的生成」 | 「这个东西的意义是什么」 |

四条箭头互不排斥，但**不能在同一条论证里互换**。一篇稿子若先按政治经济学说「平台征取」，再按生活世界说「用户自主选择」，两句话会互相取消——前者预设选择集被压缩，后者预设选择集真实存在。

---

## 2. 每条路线的第一个问题

提问的目的是让用户在两分钟内做出选择，不是考他。每条路线只给一个「第一问」，回答得上就走这条。

- **平台政治经济学**：这件事里有没有一条可追踪的钱流（订阅、佣金、广告、云服务费、补贴）？能不能拿到价格、费率或合同条款？
- **算法权力与批判**：这件事里有没有一个「被系统判定」的时刻（拒绝、降权、封号、限流、定额、定价）？当事人能不能知道理由、能不能申诉？
- **不平等与生活世界**：这件事里有没有两类人做同一件事而结果不同？或者有没有一个具体家庭／个人把新东西安放进自己的秩序？
- **数字方法**：这件事有没有留下可获取的行为记录？能不能设计一个对照（对照组、断点、随机分配）？

四问里通常只有一个能立刻回答「有」。那个就是主路线。

---

## 3. 提问模板（只用一次，控制在一屏内）

**规则**：一条消息、一张表、四个自测题、一句收束。不要给四个路线的优缺点综述。

```
这件事可以从四个方向切入，差别不在于题目，而在于你要解释什么：

| 方向 | 你最后能说的是 | 需要的材料 |
|---|---|---|
| 平台政治经济学 | 这类平台为什么长成这样、钱被谁截住、谁退不出去 | 费率/合同/财报/采购公告/接口文档 |
| 算法权力与批判 | 哪个环节被判定、当事人为何无从申诉、哪种治理手段对它无效 | 部署链条/输出样本/申诉记录/条文 |
| 不平等与生活世界 | 同样一件事，为什么两类人结果不同；东西怎样被安放进生活 | 调查与量表 / 田野与访谈 / 家庭观察 |
| 数字方法 | 这个分布或这个效应在什么条件下成立、有多稳 | 行为痕迹 / 实验 / 众包标注 |

各一条自测题：
1. 你能指出一条钱流吗？（能 → 政治经济学）
2. 你能指出一个「被判定」的时刻吗？（能 → 算法批判）
3. 你能指出两类人的结果差异吗？（能 → 不平等）
4. 你能拿到行为记录或造一个对照吗？（能 → 数字方法）

你更想走哪条？如果都沾一点，告诉我你手上已经有什么材料，我按材料替你定。
```

三条使用纪律：

1. **不要把这四条说成「四个层次」**。它们不是从宏观到微观的排列，而是四种不同的解释对象。说成层次会诱导用户「全都要」。
2. **不要给每条路线配一个学者名字或书名**。用户要选方向，不需要文献课。
3. **不要在提问时下判断**（「我觉得你这个题更适合算法批判」）。判断留到用户回答之后，或他明确说「你帮我选」。

---

## 4. 用户回答之后：三种典型回应

**「我选 A」** → 直接进对应路线文件，不要再确认一遍。若他的材料明显缺该路线的必要条件（例如选算法批判但没有部署链条），用一句话提醒，并给「补材料」与「换路线」两个选项，不要长篇劝阻。

**「你帮我选」** → 按 §5 的默认表定，说三句话：定哪条、为什么（一句）、换另一条会变成什么样（一句）。

**「四条都要」** → 不要答应「全做」，给一个主 + 一个辅的组合（§6），并明确指出哪一步不能合并。学术写作里「全都要」的实际后果是四条都做不深。

---

## 5. 默认规则（用户让你选时）

| 用户手上的材料 | 默认路线 | 理由（一句话） |
|---|---|---|
| 财报、费率、合同、采购公告、接口文档 | 平台政治经济学 | 有价格就能算分配，没有价格这条路线寸步难行 |
| 平台规则文本、申诉记录、输出样本、监管条文 | 算法权力与批判 | 有决策点就能问问责，无需总量数据 |
| 问卷、量表、面板数据、田野笔记、访谈 | 不平等与生活世界 | 组间比较或意义过程，二者都需要人的位置信息 |
| 行为日志、抓取数据、可做 A/B 的场景 | 数字方法 | 有痕迹就能估分布，但必须先交代生成机制 |
| 只有二手报道与评论 | 先做 `discipline-map` + `debates` 的定位，再定路线 | 二手材料只能支撑「议题」不能支撑「发现」 |

一句话原则：**材料决定路线，不是兴趣决定路线。** 兴趣决定选题，材料决定能写成什么。

## 6. 合法组合与禁止混用

### 6.1 三个稳定组合

**组合一：政治经济学（主）+ 算法批判（辅）**
用法：先用政治经济学说明收益结构，再用算法批判说明这套结构靠什么判定装置维持。
产出：一篇讲「平台如何以排序/评分为收益装置」的论文。
不能混的地方：政治经济学讲的是**收益归属**，算法批判讲的是**判定正当性**。前者不能替后者作辩护（「因为要盈利，所以必须排序」不是正当性论证）；后者也不能替前者算账。

**组合二：不平等（主，结构层）+ 数字方法（辅）**
用法：用痕迹或行政数据补上调查缺的分布，用调查补上痕迹缺的构念。
产出：一篇有分布、有机制的分层研究。
不能混的地方：痕迹测的是**行为**，调查测的是**态度与自报**。两者不可互相替代，也不可把行为差异直接解释成态度差异。

**组合三：生活世界（主）+ 理论桥（辅）**
用法：用驯化或亲密关系的框架解释安置过程，用理论桥处理「技术是不是行动者」。
产出：一篇质性研究，理论部分不再写成「技术与社会互动」。
不能混的地方：生活世界给的是个案过程，不能外推为总体比例。

### 6.2 三组常见的有害混用

| 有害混用 | 症状 | 后果 |
|---|---|---|
| 政治经济学 + 生活世界（同一论证内） | 「平台压缩了选择，但用户自主选择……」 | 前提互相取消，审稿人一问就塌 |
| 算法批判 + 数字方法（把审计当效应估计） | 「审计发现差别定价，因此算法造成 X% 不平等」 | 审计给存在性，效应量需另一套设计 |
| 数字方法 + 生活世界（用痕迹解释意义） | 「点击率下降说明青年失去意义感」 | 行为指标被读成意义，构念效度崩 |

判断是否混错，只需问一句：**这两条路线的因果箭头能不能在同一张图上画出来而不打架。** 画不出来就是混错。

## 7. 错配诊断（选了 A，材料像 B）

四种错配，各有两种处理：换材料，或换路线。**先给换路线，再给换材料**——因为换路线通常更快。

| 症状 | 诊断 | 处理 |
|---|---|---|
| 选了算法批判，但拿不到任何部署信息 | 没有「决策点」，只有「系统的传闻」 | 换路线：改走不平等（用调查测感知与后果），或把题目改成「关于算法的公共话语」（转话语分析，不属本 skill 四条路线） |
| 选了政治经济学，但只有访谈 | 没有价格与合同，无法追踪钱流 | 换路线：改走生活世界或劳动过程；或换材料：补平台规则文本、费率页、采购公告 |
| 选了不平等，但样本是同一类人 | 没有组间变异，做不出分层 | 换路线：改走生活世界（在同类人中做过程研究）；或换材料：加对照组 |
| 选了数字方法，但数据来自平台单方提供 | 生成机制不可知，无法评估覆盖 | 换路线：改走算法批判（把不透明本身当对象）；或换材料：自采痕迹 + 声明生成机制 |

另有一类错配不是路线问题，是**题目问题**：题目本身要求因果结论（「数字技术是否导致青年焦虑」），而四条路线里只有数字方法能做因果，且需要可行设计。此时应直接告诉用户：**这个题目要么改写成条件命题，要么补设计**。

---

## 8. 什么时候不问路线

三类请求不问，直接答：

1. **概念答疑**（「什么是可供性」「数字资本和数字素养什么区别」）→ 查 `glossary.md`，按概念归属答，不引入路线。
2. **学科定位**（「数字社会学是什么」「和计算社会科学什么关系」）→ 读 `discipline-map.md`。
3. **知识点串联**（「帮我理一遍数字不平等的主要模型」）→ 直接给层次模型与各层指标。

判断标准很简单：**用户在问「是什么」还是「怎么做」。** 问「是什么」不问路线；问「怎么做」且涉及解释路径，才问。
